# 粉笔灰纸甜丧插画（chalk-gray-sweetgloom）

把人像、角色、照片或文字主题，转成灰调粉笔手绘甜丧 Q 版插画：磨砂纸颗粒底、粉笔干刷飞白、下垂豆豆眼、淡粉腮红、低饱和灰黑白、白粉笔星芒漩涡装饰与手写短句。

## 安装

把本仓库作为技能目录克隆（或下载解压）到你环境的 `.user_skills/` 下，保持文件夹名为 `chalk-gray-sweetgloom`：

```text
workspace/.user_skills/chalk-gray-sweetgloom/
├── SKILL.md
├── agents/
│   ├── doubao.yaml
│   └── openai.yaml
└── references/
    └── prompt-blueprint.md
```

刷新 / 重启技能面板后，即可看到中文名「粉笔灰纸甜丧插画」。

## 使用

对话中说「用粉笔灰纸甜丧插画帮我画……」，或调用：

```text
$chalk-gray-sweetgloom
```
