# 提示词蓝图与变体库

拼装提示词时按「纸底笔触 → 比例五官 → 主体造型 → 装饰与文字 → 配色气质 → 负面规避」顺序组织。

## 一、文生角色 · 正向模板

```text
中性灰磨砂纸背景，纸张颗粒与复印噪点，粉笔蜡笔炭笔干刷手绘质感，边缘柔和晕染，色块不均带飞白。
{画幅}构图，角色居中偏下，Q 版大头小身 2.5 头身。
<point>主体中心X 中心Y 宽 高</point> {种族/发型耳型}，{服装}，{道具/姿态}，{伴宠}，下垂豆豆眼，长睫毛，淡粉腮红。
周围白色粉笔手绘{装饰母题}，角色{方位}一句清晰手写粉笔{语言}短句 "{短句}"。
低饱和{灰黑白/点缀色}基调，大量灰底留白，{气质}，干刷涂抹痕迹明显。
避免：{负面清单}
```

### 装饰母题（按角色主题挑 2–4 种）

- 四角星芒、小圆点、螺旋漩涡、缠绕线圈、短弧线、虚线轨道
- 水波纹与气泡点、枯枝线条、弯月与星轨、书页线、漂浮虚线、礼花短线、玫瑰花瓣轮廓、轨道圆环

### 点缀色（每种只用于局部，不可铺满）

浅粉（发色/腮红/玩偶）、灰紫（斗篷/帽子）、灰蓝（鱼尾/围裙）、灰棕（卫衣/熊耳）、灰银（铠甲）、灰红（披肩，注明低饱和）。

### 短句库（手写体，字母清晰）

Stay close. / Tea time. / Crowd the night. / Pearl tide. / Moon spell. / Read slowly. / Boo gently. / Soft circus. / Rose guard. / Orbit you. / Will you stay? / Keep quiet.

中文短句需注明「手写中文粉笔字，笔画清晰」。

## 二、图生图转画风 · 正向模板

```text
以第一张图的角色与构图为内容基础：{从内容参考提取的主体发型、服装、道具、姿态，逐项简述}。
把整张图转换为粉笔灰纸手绘画风：中性灰磨砂纸背景带纸张颗粒与复印噪点，粉笔/蜡笔/炭笔干刷手绘质感，边缘柔和晕染、色块不均带飞白；
Q 版大头小身比例，下垂豆豆眼、长睫毛、淡粉腮红；低饱和灰黑白为主，{是否保留点缀色}；
四周散布白色粉笔手绘{装饰母题}；{是否配短句及内容}；大量灰底留白，甜丧忧郁软萌气质，{画幅}构图。
避免：{负面清单}
```

- 多张参考时：第一张为内容参考，其余仅作画风参考；提示词只描述要转成的画风，不引用参考图编号之外的细节。
- 用户未要求保留的服装、配饰、动作、背景，不主动复述进内容段。

## 三、负面规避清单（统一附在末尾）

```text
避免：写实人脸，真人皮肤质感，3D 渲染，光滑矢量线稿，高饱和艳色，硬边阴影，复杂密集背景，乱码错拼字母，水印，Logo，多余肢体，畸形五官，尖锐棱角，照片级细节。
```

## 四、角色变体方向（成套创作时互相错开）
